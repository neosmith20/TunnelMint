# Support

WireHush is currently in early development.

## Getting Help

For installation problems, configuration questions, bugs, or feature requests, use the repository's GitHub Issues unless the matter is security-sensitive.

When asking for help, include:

- WireHush version or commit;
- operating system and version;
- what you expected to happen;
- what actually happened;
- clear reproduction steps;
- relevant logs with secrets removed.

Do not post private keys, credentials, full private tunnel configurations, authentication tokens, or other sensitive information.

## Security Issues

Do not use a normal public support issue for security vulnerabilities. Follow `SECURITY.md` instead.

## Scope

Support is provided on a best-effort basis. Early development builds may be incomplete or unstable and are not production-supported unless a release explicitly states otherwise.
